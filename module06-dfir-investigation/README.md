# Module 06 — DFIR Network Investigation

`Status: Planned`

## Scenario

A company has identified unusual network activity on one of its computers. Communication with unknown external infrastructure and possible data movement are suspected.

## Objective

Investigate the incident end to end: identify the hosts involved, analyse addresses, connections and services, analyse PCAPs, correlate Suricata alerts, build a timeline, identify IOCs, formulate hypotheses, and clearly separate evidence from assumptions.

## Planned deliverables

- `timeline.md`: UTC-normalised timeline of events
- `iocs.md`: indicators of compromise
- `final-report.md`: Executive Summary · Investigation Scope · Network Architecture · Evidence Collected · Technical Findings · Timeline of Events · Indicators of Compromise · Analysis and Interpretation · Limitations · Recommendations · Technical Reproducibility
